PersonalSystem Hub

A personal, locally operated MCP integration hub that lets its owner use their Google calendars and documents through compatible AI clients, including Claude Desktop and Codex.

The owner authorizes their Google accounts directly using their own Google OAuth application. This site contains only public application information. It does not display personal calendars, documents, account credentials or authorization results.

Google integration

The hub can list calendars, read selected events, search Drive file metadata, and read selected Google Docs, Sheets ranges and Slides text. Its current writing tools create individual calendar events without invitations and append bounded text to a Google Doc when the owner explicitly requests it.

Google authorization scopes include calendar read access, event access, Drive read access and Google Docs access. Google's Docs scope is broader than the actions exposed by this hub. The hub has no tool for deleting documents, changing sharing permissions or exporting credentials.
