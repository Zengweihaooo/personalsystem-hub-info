PersonalSystem Hub privacy policy

Prepared 11 October 2026. This policy describes the personal Google integration operated by the application's owner.

Data accessed and purpose

The hub verifies the authorized account's email address, reads calendar and Drive metadata, and retrieves selected events or document content to carry out the owner's requests. Account selection is explicit. Data access is bounded by the tool and the selected file, range, slide or time window.

Storage and recipients

OAuth credentials and refresh tokens are stored in a private local runtime directory on the owner's Mac. They are used to contact official Google APIs and are not returned to AI clients. Google document content is not cached by this adapter. Audit records contain tool-call metadata, not arguments, document text or credentials.

When an AI client calls a reading tool, the requested result is returned to that client. If that client uses a cloud AI service, the result may be processed by that service under the owner's account settings and the service's policies. Local credential storage does not make these AI requests entirely local.

Changes and control

The current hub exposes event creation and bounded Google Docs append operations only. Writing requires an explicit owner request. It does not expose deletion, sharing changes, invitations or arbitrary Google API access. The owner can revoke access through their Google account's third-party connections and remove local credentials to disconnect an account.

Use limitations

This integration does not sell Google user data or use it for advertising. Access and transfer are limited to providing the owner's requested personal productivity features. Use of Google API data must comply with the Google API Services User Data Policy, including its Limited Use requirements. AI-client processing is subject to applicable Google policy restrictions.
